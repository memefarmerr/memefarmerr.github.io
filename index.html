Couchbox OS

Turn an old laptop, desktop or mini PC into a controller-friendly living room console.

Installing Couchbox OS erases the drive it is installed on, and it cannot be undone. It replaces the operating system that is on the computer. Everything on that drive is destroyed. Put anything you want to keep on another drive first.

Try it before you decide anything

The image runs as a live system from the USB stick, in memory. No disk is touched while it is running, so you can check the machine you actually own:

  • picture and sound on the television
  • networking, wired and wireless
  • a USB game controller, and a keyboard

If something does not work, switch the machine off. Nothing has changed. Installing is a choice you make from the live system, inside the installer, where the drive is named and the same warning is repeated.

Download

Download the latest image

amd64, for 64-bit Intel and AMD machines. Write it to a USB stick with a disk imager, then start the machine from that stick.

What it needs

  • a 64-bit Intel or AMD machine, roughly 2012 or newer where practical
  • 4 GB of memory, 8 GB recommended. A mechanical hard drive is fine
  • HDMI video and audio, for a television
  • a USB game controller, and a keyboard. A mouse is useful but never required

Updates

An installed machine updates in two parts, both with Debian's own tools. Debian keeps the operating system current. The Couchbox archive keeps the dashboard and its launchers current, and it carries Couchbox's own packages only, never a copy of Debian:

sudo apt update && sudo apt upgrade

To stop using the Couchbox archive, remove its source file (/etc/apt/sources.list.d/couchbox.sources) and the keyring it is verified with (/usr/share/keyrings/couchbox-archive-keyring.gpg). Packages that came from the archive stay installed and stay at the version they are at.

Source, and other people's software

Couchbox OS is a derivative of Debian, and its own code is in the project's repository. The applications it can install remain the property of their authors and are fetched from their own sources: they are not redistributed here.
